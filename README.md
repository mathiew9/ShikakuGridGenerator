# Rectangle Generator

Outil de génération de grilles de Shikaku.

## Fonctionnalités

- Génération de grilles de 5×5 à 25×25
- Paramètres de génération configurables
- Validation et contrôle de l'uniformité
- Détection des doublons
- Vérification des solutions uniques
- Tentative de rendre unique une grille ayant plusieurs solutions
- Sélection et suppression des grilles
- Import et export de bibliothèques de grilles en JSON
- Logs de génération et de vérification

## Installation

```bash
npm install
```

## Lancer le projet

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Technologies

- React
- TypeScript
